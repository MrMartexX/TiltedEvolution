# External research index

Status: Evidence snapshot index

Research documents capture dated evidence from upstream repositories, issues,
pull requests, forks and related mods. They are inputs to design and planning;
they do not make external code accepted in this fork.

- [Upstream and ecosystem review — 2026-09-13](UPSTREAM_ECOSYSTEM_REVIEW_2026-09-13.md)

Every implementation based on an external source still requires a clean slice
from the current integration baseline, provenance and license review, local
regression tests, all required CI, and live evidence appropriate to its risk.
